# Changelog

## 0.1.0 - 2026-05-06

Initial MVP:

- Electron desktop shell for Windows, macOS, and Linux.
- First-run Git setup wizard.
- Project scanner with ignore rules, binary detection, source detection, sizes, and token estimates.
- AI patch prompt generator for ChatGPT, Claude, Gemini, and generic LLMs.
- Patch import/paste, unified-diff parser, security validation, dry check, and controlled apply.
- File, hunk, and eligible line approval with filtered patch generation.
- Unified and side-by-side diff views.
- Magic Flow guided workflow.
- Public-domain licensing through the Unlicense.
- Stronger patch safety checks for version-control metadata paths, symlink patch modes, and option-looking Git diff references.
- GitHub-ready docs, CI, issue templates, Pages landing page source, and tests.
