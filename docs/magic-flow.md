# Magic Flow

Magic Flow is the guided PatchBridge workflow:

1. Select project folder.
2. Scan project.
3. Select files and folders for source context.
4. Describe the desired change.
5. Select target AI model.
6. Generate an optimized patch prompt.
7. Copy or refine the prompt.
8. Paste or import the AI-generated patch.
9. Validate patch structure, paths, and dry apply.
10. Preview the diff.
11. Preview before/after content for affected text files.
12. Approve files, hunks, or eligible lines.
13. Apply the approved patch.
14. Review working tree and commit externally when satisfied.

Each step also exists as an independent tool in the sidebar.
