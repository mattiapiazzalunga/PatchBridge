# Code of Conduct

PatchBridge is a collaborative developer tool project. We expect contributors to:

- Be respectful and constructive.
- Assume good intent while still being clear about risks.
- Keep feedback focused on the work.
- Avoid harassment, discrimination, or personal attacks.
- Respect privacy and security concerns.

Maintainers may remove comments, close issues, or restrict participation when behavior makes the project less safe or less useful for others.

Report conduct concerns through the security contact listed in [SECURITY.md](SECURITY.md) if a private channel is needed.
