# Roadmap

## 0.1.x

- Add syntax highlighting to diff lines.
- Improve rename and mode-change visualization.
- Add a richer before/after file preview for imported patches.
- Add better empty/error states for non-Git projects.
- Capture official screenshots for docs and GitHub Pages.

## 0.2.x

- Add optional patch export after filtering.
- Add safer revert helpers for Git repositories.
- Add a command palette.
- Add repository-level prompt presets.
- Add configurable ignore rules and context limits.

## 0.3.x

- Add signed release automation.
- Add localization framework.
- Add optional plugin hooks for local-only tools.
- Add accessibility audit and keyboard navigation pass.

## Future

- Optional local LLM integrations only after a privacy and security design review.
- Native Tauri port investigation if contributor demand justifies the Rust toolchain.
