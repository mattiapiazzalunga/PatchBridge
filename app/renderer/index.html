How PatchBridge works

Core workflow

  1. Open a project.Select the local folder you want PatchBridge to inspect and patch.
  2. Scan context.Choose only the files that the AI model needs to understand the requested change.
  3. Generate a prompt.Describe the change, choose a target model, then copy the generated patch request.
  4. Import the patch.Paste or import the `.patch` or `.diff` returned by the AI tool.
  5. Validate and review.PatchBridge checks structure, path safety, and `git apply --check` before anything is applied.
  6. Approve and apply.Accept or reject files, hunks, and changed lines, then apply only the approved patch.

About the creator

PatchBridge is created by Mattia Piazzalunga as a local-first workflow for reviewing AI-generated code patches with more control and less guesswork.

What each area is for

WorkflowGuides the whole process from project selection to final diff review.
ScanBuilds project context while avoiding build outputs, binary files, and common noisy folders.
PromptCreates an AI-ready instruction that asks for a Git unified diff only.
ReviewParses, validates, previews, filters, applies, and can reverse the last patch from the session.
DiffShows the current working tree or imported patch against the selected project.
SetupHighlights missing Git, Node.js, or npm requirements before source-launch workflows continue.
