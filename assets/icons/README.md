# Icon Assets

`logos/logo.svg` is the renderer logo source. `logos/logo.png` is the generated packaged icon source.

The desktop app and setup wizard use the SVG mark for crisp scaling. The packaged executable uses the PNG mark for Electron and installer compatibility.

Recommended generated files:

- `assets/icons/patchbridge.ico`
- `assets/icons/patchbridge.icns`
- `assets/icons/png/16x16.png`
- `assets/icons/png/32x32.png`
- `assets/icons/png/256x256.png`
- `assets/icons/png/512x512.png`
